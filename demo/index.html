    About this functionality demo ↗

    This is a static simulation of the repository’s missing-package recovery scenario. AAP supports RBAC, credential handling, job logging, and activity auditing; this visualization does not attest that every possible control is configured. Agent instructions prescribe AAP-only remediation, and hardening work remains, including catalog access and tool restrictions. MCP routes shown here describe this recovery flow, not a proof of enforced isolation.
